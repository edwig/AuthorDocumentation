RECURRING ISSUES
================
- HTML Help system is NOT unicode compliant. HHP, HHK, HHC files are ANSI MBCS only
  Files can be UTF-16 but without a BOM. This is a problem for non-ANSI characters in 
  the index and table of contents.
  Other languages can only be supported on Windows where the default locale is set to 
  the language of the help system. And even then the index and TOC doe not work properly.

  Help pages are editted in the MSHTML editor. The editor is unicode compliant!

- Altering CSS sheets sets a need to save-and-reload the page. 
  Rendering of the styles will otherwise not follow.
  Tried: Document2.location.reload -> doesn't work
         Document3.recalc          -> doesn't work
  Work around: Navigate2(full-url)
- @media is not implemented. Implement? No, IE does not support!
- various "%" and "px" interfaces on boxes (zoom / width&height on layers)
- BUG in Tidy: it treats MARQUEE as an in-line element instead of a block element
- BROWSE MODE must react other then normal EDIT mode !!!
- TAGS: COL / COLGROUP not to be supported in AuthorDocumentation
- TAGS: BDO to be implemented
- TAGS: BASE. No: the HPP project provides the base. 
  Later on implementation of a basic WebHelp, <BASE> should be reconsidered.
