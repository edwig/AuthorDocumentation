RELEASENOTES AuthorDocumentation (AuthorHTML)
=============================================

Version 1. 0.6
--------------
1) Removed the empty entry in the RecentFileList for the startup dialog
2) Fixed the scripts dialog in the topic-properties dialog to correctly 
   show the internal scripts on a topic page.
3) Editting the default font also changes the font in the TOC on screen
   and in the project file and compiled CHM.

Version 1.0.5
-------------
1) Reworked the "New project" function from the start dialog
   Now creates a full new project with reasonable defaults, a window
   definition and a default "Intro.html" file with a Table-Of-Contents.
   Can directly be compiled to a CHM, without having to fill in the
   project settings and window settings dialogs.
2) Default storing of the HTML files is changed to UTF-8 with BOM, 
   so that the files are correctly read by the browser and the help compiler,
   and that we can correctly use international characters in the HTML files.
3) X-UA-Compatible meta tag can now be set in the topic-properties dialog, 
   so that the browser can correctly render the HTML files in HTML5 and CSS3.
   Doing so will however remove the ability to show the tag icons and the
   end-of-paragraph icons in the browser, since these are not supported in HTML5.

Version 1.0.4
-------------
1) Editting of TOC entries is re-enabled again from the TOC view.
   A edit icon has been added there to edit the current entry.
2) The TOC can now save the image number again without altering any other
   part of the TOC entry properties.
3) Fix for saving multi-level topic keywords. The second en higher levels
   are now correctly stripped from leading and trailing spaces.
4) Fix for the broken link detector. The BrokenLinks Dialog is now 
   displaying no more false positives.
5) Restored the split-cursors for gripping the panes
6) Resizing of the list on the startup dialog.
7) Rewritten the addressCombo box for various dialogs to work more correctly
   with the relative and absolute pathnames.
8) Broken-links detector is upgraded for better yields on the results.
   relative paths did lead to false positives, now the relative paths are 
   resolved to absolute paths before checking.
9) Fixed URLDlg to open a page outside of an CHM project.

Version 1.0.3
-------------
1) Reading/Writing HHP, HHC and HHK files are now implemented with WinFile
   This makes it possible to read/write the BOM of the files.
2) Rewritten the read/write of the *.CSS files
3) Extra checks on the files in the window definition. TOC and HKK must
   be relative pathnames there.
4) Fully support all CSS measurement units:
   
   // Absolute size
   px      // Pixels ( 1/96 of an inch)
   in      // Inch
   cm      // Centimeter (1/2.54  of an inch)
   mm      // Millimeter (1/25.4  of an inch)
   Q       // Quarter    (1/101.6 of an inch)
   pt      // Point      (1/72    of an inch)
   pc      // Pica       (1/6     of an inch)
   // Relative size
   %       // Percentage of the browser viewport
   ex      // Height of the fonts 'x' character
   em      // Width of the em of a font
   rem     // Width of the em of the root font
   vh      // Percentage of the viewport height
   vw      // Percentage of the viewport width
   vmin    // Percentage of the minimum of viewport(width and height)
   vmax    // Percentage of the maximum of viewport(width and height)

5) Fix for entering bookmarks and hyperlinks again by selecting text and converting
   it into a bookmark or hyperlink by the apropriate command.
6) Custum dictionaries and ignore lists per selected language, so that the additions 
   to the standard spelling libraries will be split on a per-language basis.
7) Spelling correction now corrects for quotes that the browser editor sees as part
   of the word the spell-correct. The quotes are now not entered in the dictionary
   any more.
