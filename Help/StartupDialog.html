STARTUP

This is the first dialog you see aft er starting the application. Here you can do one of the following:

  1. Open a documentation project you have been working on previously. Just select the project from the list on the right
  2. Search for a documentaion project on the filesystem (button OPEN)
  3. Work on one of the last used 15 files (button Get the list of recent files)
  4. Start a new documentation project (button NEW project)
  5. Start a new documentation page (button NEW file)
  6. Import an existing CHM as a new documentation project in an empty directory (button IMPORT)
