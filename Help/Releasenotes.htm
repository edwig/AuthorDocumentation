Releasenotes

Version 1.0.6

  • Changed the default release to Unicode build. CSS and HtmlTidy have been changed to work with the Unicode version HHP, HHC and HHK files can be stored in DBCS (Double-Byte-Character-Set) mode to accomodate asian languages, like Chinese, Kanji, Korean or Vietnamese.
  • Added the topic ID to the keywords section (see 3th tab on the Topic dialog) You can add an ID and alias to the keyword list, that can be exported to the [MAP] and [ALIAS] sections of the HHP file.
  • Re1moved the empty entry in the RecentFileList for the startup dialog
  • Fixed the scripts dialog in the topic-properties dialog to correctly show the internal scripts on a topic page.
  • Editting the default font also changes the font in the TOC on screen and in the project file and compiled CHM.
  • Various fixes for CSS and the CSS editor. The decomposition and composition of properties has been fixed.

Version 1.0.5

  • Reworked the "New project" function from the start dialog Now creates a full new project with reasonable defaults, a window definition and a default "Intro.html" file with a Table-Of-Contents. Can directly be compiled to a CHM, without having to fill in the project settings and window settings dialogs.
  • Default storing of the HTML files is changed to UTF-8 with BOM, so that the files are correctly read by the browser and the help compiler, and that we can correctly use international characters in the HTML files.
  • X-UA-Compatible meta tag can now be set in the topic-properties dialog, so that the browser can correctly render the HTML files in HTML5 and CSS3. Doing so will however remove the ability to show the tag icons and the end-of-paragraph icons in the browser, since these are not supported in HTML5.

Version 1.0.4

  • Editting of TOC entries is re-enabled again from the TOC view. A edit icon has been added there to edit the current entry.
  • The TOC can now save the image number again without altering any other part of the TOC entry properties.
  • Fix for saving multi-level topic keywords. The second en higher levels are now correctly stripped from leading and trailing spaces.
  • Fix for the broken link detector. The BrokenLinks Dialog is now displaying no more false positives.
  • Restored the split-cursors for gripping the panes
  • Resizing of the list on the startup dialog.
  • Rewritten the addressCombo box for various dialogs to work more correctly with the relative and absolute pathnames.
  • Broken-links detector is upgraded for better yields on the results. relative paths did lead to false positives, now the relative paths are resolved to absolute paths before checking.
  • Fixed URLDlg to open a page outside of an CHM project.

Version 1.0.3

  • Reading/Writing HHP, HHC and HHK files are now implemented with WinFile This makes it possible to read/write the BOM of the files.
  • Rewritten the read/write of the *.CSS files
  • Extra checks on the files in the window definition. TOC and HKK must be relative pathnames there.
  • Fully support all CSS measurement units: 
    // Absolute size
px      // Pixels ( 1/96 of an inch)
in      // Inch
cm      // Centimeter (1/2.54  of an inch)
mm      // Millimeter (1/25.4  of an inch)
Q       // Quarter    (1/101.6 of an inch)
pt      // Point      (1/72    of an inch)
pc      // Pica       (1/6     of an inch)

// Relative size
%       // Percentage of the browser viewport
ex      // Height of the fonts 'x' character
em      // Width of the em of a font
rem     // Width of the em of the root font
vh      // Percentage of the viewport height
vw      // Percentage of the viewport width
vmin    // Percentage of the minimum of viewport(width and height)
vmax    // Percentage of the maximum of viewport(width and height)
  • Fix for entering bookmarks and hyperlinks again by selecting text and converting it into a bookmark or hyperlink by the apropriate command.
  • Custum dictionaries and ignore lists per selected language, so that the additions to the standard spelling libraries will be split on a per-language basis.
  • Spelling correction now corrects for quotes that the browser editor sees as part of the word the spell-correct. The quotes are now not entered in the dictionary any more.
